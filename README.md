# 🛠️ Task Tracker — Backend (Node.js + PostgreSQL)

A secure and scalable REST API powering the Task Tracker App.  
Handles authentication, CRUD operations, PostgreSQL database queries, and production deployment.

---

## ⚙️ Features

- User Registration & Login
- JWT Authentication
- CRUD for tasks
- PostgreSQL model
- Automatic CORS handling
- Production-ready deployment settings

---

## 🛠️ Tech Stack

- Node.js
- Express.js
- PostgreSQL
- pg library
- JWT Authentication
- Render Deployment
- dotenv (Environment variables)
- CORS
